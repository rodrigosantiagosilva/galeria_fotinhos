## Sobre o projeto

O **Galeria Fotinhos** é um aplicativo desenvolvido para dispositivos móveis que permite ao usuário criar e visualizar uma galeria de fotos.

O aplicativo possui acesso à **câmera do dispositivo**, permitindo que o usuário tire fotos diretamente pelo aplicativo e as utilize na galeria.

O projeto foi desenvolvido utilizando **Ionic**, **Vue** e **Capacitor**, com foco no desenvolvimento de aplicações para dispositivos móveis.

## Como rodar o projeto

### 1. Clonar o repositório

Primeiro, clone o repositório do projeto:

```bash
git clone https://github.com/rodrigosantiagosilva/galeria_fotinhos
```

Depois, entre na pasta do projeto:

```bash
cd galeria_fotinhos
```

### 2. Instalar as dependências

Execute o seguinte comando no terminal:

```bash
ionic install
```

### 3. Sincronizar o Capacitor

Após instalar as dependências, execute:

```bash
npx cap sync
```

### 4. Abrir no Android Studio

Para abrir o projeto no Android Studio, utilize:

```bash
npx cap open android
```

Depois disso, o projeto poderá ser executado em um dispositivo Android físico ou em um emulador através do Android Studio.
